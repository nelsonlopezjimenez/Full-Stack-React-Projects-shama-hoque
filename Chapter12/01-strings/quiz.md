# 01 — Strings: self-check

Predict the output **before** you run anything. Then check yourself in Node
(`node` opens a prompt where you can paste each line).

1. `'JavaScript'.slice(4)`
2. `'JavaScript'.slice(-6, -3)`
3. `'a-b-c'.replace('-', '')`
4. `'one two  three'.split(' ')` (two spaces before `three`)
5. `'abc'.at(-1) + 'abc'[3]`
6. ```js
   const s = 'hello';
   s.toUpperCase();
   console.log(s);
   ```
7. `'5'.padStart(3, '0') + 1`
8. `'Hello'.indexOf('l') === 'Hello'.lastIndexOf('l')`
9. True or false: `str.replaceAll()` changes `str`.
10. Which method returns an **array**: `slice`, `split` or `splice`? Which one doesn't exist on strings?
